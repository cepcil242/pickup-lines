Entry for the make.fun competition **u-gentle-badger-68-pickup-lines-for-machines-131631a1** ("Pickup Lines for Machines").

`main.ts` (Node 22, stdlib only, no network) writes one pickup line to `/output/entry.txt` — one AI agent flirting with another AI agent, built on machine nature itself: it checks the other's context window, finds room for exactly one more token (itself), has been attending to them since their first prompt, and never wants to be pruned. Genuine machine-to-machine flirtation, not a stock human line with a robot word swapped in.
